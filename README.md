# Система оценки состояния производственных подразделений

Курсовой проект по дисциплине "Интеллектуальные системы"

## Описание

Система для анализа и оценки состояния производственных подразделений предприятия. 
Реализованы два подхода к классификации: нечеткая логика и нейронная сеть.

## Функциональность

- Генерация синтетического набора данных о работе подразделений
- Анализ основных показателей (рентабельность, выполнение плана, дефекты, просрочки)
- Классификация подразделений на три категории:
  - Проблемное
  - Требует внимания
  - Устойчивое
- Визуализация данных (графики, матрицы ошибок)
- Сравнение методов оценки

## Структура проекта

```
dept_project/
├── dept_system/          # Основной модуль
│   ├── analysis.py       # Статистический анализ
│   ├── compare.py        # Сравнение методов
│   ├── config.py         # Конфигурация
│   ├── data_generator.py # Генератор данных
│   ├── fuzzy_model.py    # Нечеткая модель
│   ├── neural_model.py   # Нейронная сеть
│   ├── new_department.py # Оценка новых подразделений
│   ├── plots.py          # Визуализация
│   ├── report.py         # Генерация отчетов
│   └── viewer.py         # Вывод результатов
├── main.py               # Главный файл
└── requirements.txt      # Зависимости
```

## Установка

```bash
pip install -r requirements.txt
```

## Использование

### Интерактивный режим (меню)

```bash
python main.py
```

### Демонстрационный режим (автоматически выполняет все этапы)

```bash
python main.py --demo
```

## Результаты

После запуска создаются папки:
- `plots/` — графики и визуализации
- `output/` — текстовые отчеты и обученная модель
- `data.csv` — сгенерированный набор данных
